# Contributing

Contributions that materially improve these public technical resources are welcome.

## Public-claim rule

All factual product, regulatory, security and compliance statements must be evidence-based.

Do not introduce unsupported claims such as:

- certified safe
- regulator approved
- guaranteed secure
- fully compliant
- officially endorsed

unless documentary evidence clearly supports the exact statement.

## Quality rule

Before submitting a change:

- check spelling and grammar
- verify links
- preserve valid UTF-8
- avoid mojibake
- avoid secrets or private data
- distinguish identity/evidence from a relying-party decision
